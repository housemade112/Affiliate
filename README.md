# CopyTrade Pro

Elite copy trading platform built with React + Vite + Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo on Vercel
3. Build command: `npm run build`
4. Output directory: `dist`

## Auth

- Admin: `admin@copy.com` / `password`
- User: Sign up freely

## Features

- 120 procedurally generated affiliate profiles
- Copy/unCopy mechanics with balance deduction
- Deposit/withdrawal request system
- Admin panel with full CRUD
- localStorage persistence
